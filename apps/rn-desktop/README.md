# @bemedev/rn-desktop

Cross-platform desktop app built with React Native and
[Expo Desktop](https://github.com/shirakaba/expo-desktop), running inside the Vite+
monorepo.

## Toolchain

Expo and Metro own bundling and native builds; Vite+ supplies the shared formatting,
linting, type-checking and test tooling of the workspace.

```bash
vp install                 # install the whole workspace
vp -C apps/rn-desktop run start
```

## Scripts

| Script     | Command                     | Description                  |
| ---------- | --------------------------- | ---------------------------- |
| `start`    | `expo start`                | Start the Metro dev server   |
| `android`  | `expo run:android`          | Build and run on Android     |
| `ios`      | `expo run:ios`              | Build and run on iOS         |
| `macos`    | `bash scripts/run-macos.sh` | Build and run on macOS       |
| `windows`  | `expo-desktop run windows`  | Build and run on Windows     |
| `prebuild` | `expo-desktop prebuild`     | Generate the native projects |
| `web`      | `expo start --web`          | Start the web target         |
| `fmt`      | `vp fmt`                    | Format with Oxfmt            |
| `lint`     | `vp lint`                   | Lint with Oxlint             |
| `check`    | `vp check`                  | Format, lint and type-check  |

Run any of them from the workspace root with `vp -C apps/rn-desktop run <script>`.

## Native projects

`android`, `ios`, `macos` and `windows` are generated by
`vp -C apps/rn-desktop run prebuild` and are ignored by git. Regenerate them after
changing `app.json` or installing native dependencies.

Dependency patches live in [`patches`](./patches) and are registered in the root
[`pnpm-workspace.yaml`](../../pnpm-workspace.yaml).
